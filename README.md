# Cliplet

Windows 上的本地剪贴板历史。复制过的文本、图片和文件留在这台电脑上，不上传。

它不是系统「剪贴板历史」（Win+V）的另一个开关。Cliplet 住在托盘里，记得住图片和文件，也能把大模型回答里的公式排出来。

## 最新版本 1.1.0

- **内置截屏**：可自定义热键（支持单独 F1 等），区域框选后带微信风格标注工具栏（矩形 / 箭头 / 画笔 / 文字 / 马赛克 / 撤销 / 保存），截完直接进剪贴板历史。
- **设置面板**：开机启动、暂停记录、选中后隐藏窗口；打开面板与截屏热键均可点按捕获，无需修饰键。
- **单击粘贴 + LRU**：点一条即贴回先前窗口，用过的记录自动顶到最前。
- **多选 / 右键删除**：筛选栏「多选」批量删；条目右键可删或置顶。
- **来源应用图标**：列表显示来自微信、Cursor 等的简洁图标。
- **覆盖升级安装包**：`Cliplet-Setup.exe` 装过旧版再装新版会直接更新，历史数据保留。

## 特点

- **文本、图片、文件都留档。** 图片文件会出缩略图；选中后可以看大图。微信截图也能显示，不会变成一块空白。
- **粘回去，而不是只停在列表里。** 单击或回车直接贴回刚才的窗口；用过的记录会排到最前。Ctrl+1 到 Ctrl+9 直接贴最近的第几条。
- **多选删除。** 点「多选」勾选后批量删除；也可右键单条删除。
- **按类型筛选。** 全部 / 文本 / 图片 / 链接 / 文件。
- **公式跟正文走。** 从大模型复制的内容如果带有 LaTeX（`$...$`、`$$...$$`、`\(...\)`、`\[...\]`），列表里会排成公式。再复制时，Word 和 WPS 能看到公式图，记事本和微信仍得到原来的 LaTeX。`$100` 这种价钱不会被当成公式。
- **选中后可以整理提示词。** 「优化提示词」在本机把这段话整理成更好发给模型的提示词，不把内容发给任何模型。
- **托盘里就能用。** 左键打开面板，右键可以暂停记录、清空未置顶、开机启动或退出。打开面板热键默认为 Ctrl+Alt+V，截屏默认为 Ctrl+Alt+A（均可在设置里改）。
- **密码框不记。** 检测到密码输入框时跳过。浏览器里的密码框识别不了。
- **数据在本机。** SQLite 数据库在 `%AppData%\Cliplet`。未置顶的记录最多留 400 条，置顶的会留下。

## 快捷键

面板打开时：

| 操作 | 结果 |
| --- | --- |
| 单击一条，或 Enter | 贴回刚才的窗口，并排到最前 |
| Ctrl+1 … Ctrl+9 | 贴最近的第 1 到第 9 条 |
| Ctrl+P | 置顶或取消置顶 |
| 多选模式下点击条目 | 勾选 / 取消勾选 |
| Delete，或 Ctrl+Backspace | 有勾选时删勾选的，否则删当前这条 |
| Esc | 先清空搜索，再关闭面板 |

全局（可在设置中修改）：

| 操作 | 默认 |
| --- | --- |
| 打开 / 关闭面板 | Ctrl+Alt+V |
| 截屏 | Ctrl+Alt+A（也可设为 F1 等单键） |

## 安装（给普通人）

1. 打开 [Releases](https://github.com/NingLing-Lys/Cliplet/releases) 下载最新的 **`Cliplet-Setup.exe`**
2. 双击按向导安装（不必单独装 .NET）
3. 若已安装旧版，直接装新包即可**覆盖升级**，剪贴板历史会保留

重新打包安装程序：

```powershell
powershell -ExecutionPolicy Bypass -File .\installer\build.ps1
```

## 开发运行

需要 [.NET 10 SDK](https://dotnet.microsoft.com/download)（`net10.0-windows`）。

```powershell
dotnet run
```

发布开发用程序：

```powershell
dotnet publish -c Release -o publish
```

生成的程序在 `publish\Cliplet.exe`。第一次运行后，从托盘图标或热键打开。
