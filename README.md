# Cliplet

Windows 上的本地剪贴板历史。复制过的文本、图片和文件留在这台电脑上，不上传。

它不是系统「剪贴板历史」（Win+V）的另一个开关。Cliplet 住在托盘里，记得住图片和文件，也能把大模型回答里的公式排出来。

## 特点

- **文本、图片、文件都留档。** 图片文件会出缩略图；选中后可以看大图。微信截图也能显示，不会变成一块空白。
- **粘回去，而不是只停在列表里。** 单击复制，双击或回车贴回刚才的窗口。Ctrl+1 到 Ctrl+9 直接贴最近的第几条。
- **多选删除。** 勾选几条后，顶部会出现「删除选中」；也可以全选当前列表再删。
- **公式跟正文走。** 从大模型复制的内容如果带有 LaTeX（`$...$`、`$$...$$`、`\(...\)`、`\[...\]`），列表里会排成公式。再复制时，Word 和 WPS 能看到公式图，记事本和微信仍得到原来的 LaTeX。`$100` 这种价钱不会被当成公式。
- **选中后可以整理提示词。** 「优化提示词」在本机把这段话整理成更好发给模型的提示词，不把内容发给任何模型。已经有公式时，会要求对方用 LaTeX 重写；只是一个问题时，会要求先给结论、并把公式写成 LaTeX。「复制公式图」则把整段排成一张图，方便贴到只收图片的地方。
- **托盘里就能用。** 左键打开面板，右键可以暂停记录、清空未置顶、开机启动或退出。全局热键默认是 Ctrl+Alt+V；如果被占用，则改用 Ctrl+Shift+Space。
- **密码框不记。** 检测到密码输入框时跳过。浏览器里的密码框识别不了。
- **数据在本机。** SQLite 数据库在 `%AppData%\Cliplet`。未置顶的记录最多留 400 条，置顶的会留下。

## 快捷键

面板打开时：

| 操作 | 结果 |
| --- | --- |
| 单击一条 | 复制 |
| 双击，或 Enter | 贴回刚才的窗口 |
| Ctrl+1 … Ctrl+9 | 贴最近的第 1 到第 9 条 |
| Ctrl+P | 置顶或取消置顶 |
| 勾选左侧复选框 | 批量选择 |
| Delete，或 Ctrl+Backspace | 有勾选时删勾选的，否则删当前这条 |
| Ctrl+A（焦点不在搜索框） | 勾选当前列表全部 |
| Esc | 先清空搜索，再关闭面板 |

## 运行

需要 [.NET 10 SDK](https://dotnet.microsoft.com/download)（`net10.0-windows`）。

```powershell
dotnet run
```

发布一个可直接运行的程序：

```powershell
dotnet publish -c Release -o publish
```

生成的程序在 `publish\Cliplet.exe`。第一次运行后，从托盘图标或 Ctrl+Alt+V 打开。
